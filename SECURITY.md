# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | ✅ Active Development |
| < v1.0  | ❌ Not Supported    |

## Reporting a Vulnerability

We take the security of Scouter seriously. If you believe you have found a security vulnerability, please report it by contacting the project maintainers directly.

### Process

1. **Do not open a public issue.**
2. Email your report to the maintainers with a detailed description of the vulnerability and steps to reproduce it.
3. We will acknowledge receipt of your report and provide an estimated timeframe for a fix.
4. Once a fix is verified, we will coordinate a public disclosure.

---
*Security and integrity are core tenets of Scouter's development.*
